# 《做个好梦》隐私政策

**开发团队：「不活泼金属元素的工作室」**
**生效日期：2026 年 10 月 20 日**
**最后更新：2026 年 10 月 20 日**

感谢你游玩《做个好梦》（以下简称"本游戏"）。本游戏由个人开发团队**「不活泼金属元素的工作室」**（以下简称"开发者"）独立开发并发行。

我们非常重视你的个人信息与隐私保护。本政策将说明本游戏如何处理与你有关的信息。**请你在使用本游戏前仔细阅读并充分理解本政策。**

---

## 一、核心结论（一分钟读完）

- 本游戏是**完全离线的单机游戏**，不联网、不注册、不登录。
- 本游戏**不收集、不上传、不共享**你的任何个人信息。
- 你唯一的"数据"是保存在**你自己设备上**的游戏设置（音量、弹幕上限、触屏按键位置），它们不会离开你的设备。
- 本游戏**不含广告、不含内购、不含第三方统计或分析 SDK**。

---

## 二、本游戏如何处理信息

### 2.1 我们收集的信息

**我们不收集任何个人信息。**

本游戏无需注册账号，不要求填写姓名、手机号、邮箱、身份证号，不读取通讯录、短信、相册、位置、麦克风、摄像头、剪贴板，也不获取你的设备唯一标识符（IMEI、Android ID、IDFA、OAID 等）。

### 2.2 仅保存在你设备本地的数据

为了让你下次打开游戏时保持上次的偏好，本游戏会把以下几项设置保存在**你的设备本地存储**中：

| 本地数据 | 用途 |
| --- | --- |
| 音乐音量、音效音量 | 记住你的音量设置，下次启动时沿用 |
| 弹幕上限（画面中同时存在的子弹数量上限） | 记住你的画面特效密度偏好，低配置设备可调低以提升流畅度 |
| 触屏按键布局（虚拟摇杆与冲刺按钮的位置坐标） | 记住你自定义的按键位置，下次启动时沿用 |

**这些数据的性质说明：**

- 存储位置：Android 系统的应用私有目录（Godot 引擎的 `user://设置.cfg` 配置文件）；Windows 版位于 `%APPDATA%\Godot\app_userdata\` 下的应用数据目录。
- **它们不会通过网络传输，不会发送给开发者或任何第三方。**
- 它们不包含任何可识别你个人身份的信息。
- 卸载本游戏时，这些数据会随应用数据一并被系统删除。

### 2.3 我们不收集的信息

为避免歧义，以下内容本游戏**明确不收集、不访问**：

姓名、手机号、电子邮箱、身份证件信息、账号密码、地理位置、通讯录、通话记录、短信、照片与相册、麦克风录音、摄像头画面、剪贴板内容、应用安装列表、设备唯一标识符、广告标识符、IP 地址、崩溃日志、使用行为统计。

---

## 三、网络与第三方服务

- 本游戏**不申请网络访问权限**（Android 版的 `INTERNET` 权限处于关闭状态），在技术上无法主动连接互联网。
- 本游戏**未集成**任何广告平台、数据分析平台、社交分享、云存档、账号登录或支付 SDK。
- 本游戏**不会向任何第三方出售、出租、共享、转让**你的信息。
- 本游戏不含任何指向外部网站的跳转（除非你主动在应用商店页面查看信息）。

---

## 四、信息的存储、保留与删除

| 项目 | 说明 |
| --- | --- |
| 存储地点 | 仅存储在你自己的设备本地 |
| 保留期限 | 直至你主动清除或卸载本游戏 |
| 跨境传输 | 不涉及（无任何数据传输） |
| 开发者侧留存 | 无。开发者没有任何服务器，也不接收你的数据 |

**你如何删除这些数据：**

1. **游戏内清除**：进入游戏「设置」界面，将音量、弹幕上限调回默认值，并在触屏布局编辑中选择「恢复默认」，即可覆盖原有设置。
2. **彻底删除**：在系统设置中卸载本游戏，本地保存的全部设置数据将被一并删除，此后无法恢复。

## 五、未成年人保护

本游戏是一款单机休闲游戏，不设账号系统，不收集任何个人信息，因此不存在针对未成年人的信息收集行为。

若你是未满 14 周岁的儿童，请在监护人的陪同下阅读本政策并使用本游戏。若监护人认为本游戏存在不当之处，可通过下方联系方式与开发者联系，开发者将及时处理。

---

如你对本政策或个人信息处理仍有疑问、意见或投诉，可通过第七节的方式联系开发者。
